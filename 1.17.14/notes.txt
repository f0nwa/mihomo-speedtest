Зеркала релизов через jsDelivr
•	После публикации релиза  cut_release.sh  выкладывает файлы и текст в ветку  dist  (тег  dist-<тег> ), обновляет указатели  channels/stable|dev , копию  install.sh , обрезает старые релизы и сбрасывает кэш jsDelivr. Опция  --no-dist  пропускает этот шаг.
•	 update.sh  при недоступном GitHub переключается на зеркала  cdn/gcore/fastly.jsdelivr.net  ( UPDATE_MIRRORS ), закрепляется за тегом  dist-<тег>  и проверяет файлы по SHA256-манифесту.
•	 install.sh  также использует зеркало, если GitHub недоступен; в README и guide добавлена запасная команда установки через jsDelivr.
•	Текст релиза при недоступном GitHub API берётся с зеркала.
•	Тест бутстрапа берёт пути файлов из  release/components.txt .
