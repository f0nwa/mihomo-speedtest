# Лёгкая диагностика соединений при установке, обновлении и удалении: дизайн

Дата: 2026-10-11. Ветка: `dev`. Принят в чате (вариант «всегда короткая проба, при
сбое - расшифровка и советы»).

## Цель

Когда загрузка с GitHub не удаётся, человек видит «код загрузчика: 28» и не
понимает, что чинить. Нужно:

- проверять, как идёт трафик самого роутера (напрямую или через mihomo), перед
  установкой и обновлением и при сбое загрузки;
- проверять не только GitHub, чтобы отличить «режут GitHub» от «нет интернета»
  и «не работает DNS»;
- сказать по-русски, что именно не так, и предложить, что настроить;
- при удалении показать состояние (ядро, бэкап конфига, что будет удалено).

## Библиотека `installer/netcheck.sh`

Один набор проб и одни правила советов для всех сценариев. Побочных эффектов при
подключении нет; вывод - через `ui_ok/ui_warn/ui_note`, если они определены, иначе
в stderr.

Пробы (curl, таймаут `NC_TIMEOUT`, по умолчанию 5 с, все параллельно):

| Имя | Адрес | Зачем |
|-----|-------|-------|
| `ip` | `https://1.1.1.1` | интернет без DNS |
| `gstatic` | `https://www.gstatic.com/generate_204` | контрольный не-GitHub хост |
| `cloudflare` | `https://www.cloudflare.com/cdn-cgi/trace` | второй контрольный хост |
| `github` | `https://github.com` | GitHub |
| `api` | `https://api.github.com` | API релизов |
| `raw` | `https://raw.githubusercontent.com` | скрипты и манифест |
| `objects` | `https://objects.githubusercontent.com` | файлы релиза |

Два пути: **напрямую** и **через mihomo** (`NC_PROXY` или порт `mixed-port`/`port`/
`socks-port` из `config.yaml`, если ядро запущено; пробы через прокси: `github`,
`raw`, `gstatic`). Результат пробы: `ok`, `dns`, `timeout`, `refused`, `reset`,
`tls`, `proxy`, `http403`/`http451`, `fail:КОД`. Любой HTTP-ответ, кроме 403/451/
429, считается «достучались».

Функции: `nc_run` (собрать), `nc_summary` (компактные строки), `nc_advice`
(советы), `nc_diagnose` (всё вместе; код 0 - GitHub доступен хоть одним путём).

Правила советов, по порядку:

1. Не отвечает никто напрямую (`ip` и контрольные): нет выхода в интернет -
   проверить WAN/кабель/провайдера.
2. `ip` отвечает, имена не резолвятся (`dns`): проверить DNS роутера
   (dns-override Keenetic, `dns:` в конфиге mihomo).
3. Ошибки `tls`: проверить время на роутере (NTP) и `opkg install ca-certificates`.
4. GitHub напрямую не отвечает, контрольные отвечают: GitHub режется. Через
   mihomo доступен - включить в XKeen проксирование трафика самого роутера или
   запускать с `INSTALL_PROXY=http://127.0.0.1:ПОРТ`; через mihomo тоже нет -
   проверить ноду и группу `Заблок. сервисы`; mihomo не запущен - запустить ядро
   либо поставить файлы вручную.
5. `http403`/`http451`: доступ блокирует провайдер или регион.
6. Часть хостов GitHub отвечает, часть нет (например, `raw` да, `objects` нет):
   частичная блокировка, `*.githubusercontent.com` должен идти через прокси.
7. Всё доступно: «сеть в порядке».

## Встраивание

- **install.sh (бутстрап).** Работает до загрузки файлов, поэтому библиотека
  встроена блоком `# >>> netcheck-bootstrap` ... `# <<< netcheck-bootstrap` -
  дословная копия `installer/netcheck.sh`, синхронность проверяет тест (как у ui).
  Перед загрузкой релиза - короткая сводка; при сбое загрузки вместо статичной
  подсказки - расшифровка и советы (статичная остаётся запасной).
- **update.sh / веб-обновление.** Сводка перед загрузкой; при сбое - расшифровка
  вместо «код загрузчика: N»; веб-обновление отдаёт её в интерфейс.
- **uninstall.sh.** Диагностика состояния: запущено ли ядро, есть ли бэкап
  конфига для отката, что будет удалено; сеть проверяется, только если скрипт
  скачан с GitHub (`curl | sh`).
- **`mihomo-speedtest doctor`.** То же вручную в любой момент.

## Тесты

Заглушка curl по таблице «хост -> код возврата и HTTP-код» для каждого пути:
классификация результата, каждое правило советов, параллельность (общее время
не больше таймаута), выбор порта прокси из конфига, `NC_PROXY`, синхронность
встроенной копии.

## Вне объёма

Автоматическое исправление сети; проверки скорости; диагностика подписок и нод
(этим занимаются прогоны и конструктор).
